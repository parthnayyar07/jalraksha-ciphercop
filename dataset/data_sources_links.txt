JalRaksha - dataset sources (Team North Eagles, CipherCop 2026, Track 2)

The raw CSVs generated by `python fetch_data.py` (folder data/raw/) are uploaded alongside this file.
They can be re-created at any time from these free, key-less public sources:

1. Open-Meteo Forecast API (live multi-model rainfall)          https://open-meteo.com/en/docs
2. Open-Meteo Historical Forecast API (past model forecasts)    https://open-meteo.com/en/docs/historical-forecast-api
3. Open-Meteo Historical Weather API (ERA5-based observations)  https://open-meteo.com/en/docs/historical-weather-api
4. Open-Meteo Elevation API (Copernicus DEM)                    https://open-meteo.com/en/docs/elevation-api
5. OpenStreetMap major roads via osmnx (optional)               https://www.openstreetmap.org/copyright
6. ECMWF ERA5 reanalysis (underlying observation product)       https://doi.org/10.1002/qj.3803  (Hersbach et al., 2020)

Files produced in data/raw/:
  localities.csv        22 Hyderabad analysis points (approximate coordinates)
  elevation.csv         point elevation + mean of 8-point 1.5 km ring (terrain susceptibility input)
  history_models.csv    daily rainfall forecasts of 3 models, 2022-06-01 .. fetch date - 6 days
  obs_era5.csv          daily observed rainfall (ERA5-based) for the same days/localities
  forecast_live.csv     7-day forecast at the time of fetching
  replay_2020.csv       rainfall 9-17 Oct 2020 (replay of the October 2020 Hyderabad floods)
  hyderabad_roads.graphml  OSM major-road graph (only with --roads)
  meta.json             fetch timestamp and sources
